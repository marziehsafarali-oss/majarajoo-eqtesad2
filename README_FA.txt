فرمانروای اقتصاد ایران — نسخهٔ آزمایشی قابل‌بازی

شروع:
1) فایل index.html را در مرورگر باز کنید.
2) از فهرست «ساخت‌وساز شهر» یک ساختمان انتخاب کنید.
3) خانهٔ خالی روی نقشه را لمس کنید.
4) با «گذر زمان» تولید، هزینه و بازار را به‌روز کنید.
5) برای ذخیره از «ذخیره بازی» استفاده کنید.

این نسخه یک نمونهٔ اولیهٔ سمت مرورگر است و برای بازی به حساب کاربری یا API پولی نیاز ندارد.
ذخیره‌سازی از localStorage همان مرورگر استفاده می‌کند.
نقشهٔ نسخهٔ اولیه ۳۶ جای ساخت دارد؛ این نسخه هنوز بازی نهایی کل کتاب اقتصاد دهم نیست و باید مرحله‌به‌مرحله توسعه و آزمایش شود.
